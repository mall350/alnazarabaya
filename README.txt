# AL NAZAR ABAYA — FREE WEBSITE

This is a static website. It does not require a database or paid hosting.

## 1. Change your WhatsApp number
Open `script.js` and find:
const WHATSAPP_NUMBER = "923001234567";
Replace it with your WhatsApp number in international format, without +, spaces or dashes.

## 2. Change products
In `script.js`, edit the `products` list:
- name
- price
- image
- description

## 3. Add product photos
Put your photos inside the `images` folder and name them:
- product1.jpg
- product2.jpg
- product3.jpg
- hero.jpg

You can use .png/.webp too, but then change the filename in script.js/style.css.

## 4. Change Instagram/TikTok
Open `index.html` and replace the example social links with your real profile links.

## 5. Publish for $0
You can upload these files to a free static hosting provider such as GitHub Pages, Cloudflare Pages, or Netlify's free tier.

Important:
- Free hosting can be free indefinitely, but no third-party service can guarantee "lifetime" availability.
- A custom .com domain normally requires a paid yearly registration.
- Your website itself can be hosted on a free provider without a monthly hosting bill.
